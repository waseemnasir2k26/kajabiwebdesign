# kajabiwebdesign (The Soul Voyage)

Landing page concept for a breathwork and sacred-geometry healing brand, The Soul Voyage: hero, about, offerings, benefits, events, testimonials and call to action.

Live: https://kajabiwebdesign.vercel.app

## Stack

React, Vite, plain CSS per component.

## Run locally

```bash
npm install
npm run dev
npm run build
```
